# 馬券勝負ボード v4.11

今回の改善内容：

1. **管理画面のTOPボタン修正**
   - 管理画面でTOPを押すと大会トップ画面へ戻り、MAX PAYOUT BOARDまで自動スクロールします。
2. **大会削除を厳重化**
   - 確認ダイアログ → 大会名の完全一致入力 → 最終確認の3段階です。
   - 参加者・レース・結果を含む大会データを完全削除する前に停止できるようにしています。
3. **レース入力画面をレトロゲーム風に刷新**
   - 16bit/アーケード風の枠線、走査線、ドット感、モノスペース文字、ピクセル風ボタンに変更。
   - レース追加・レース編集の両方に適用。
4. **参加者上限は12人**
   - 追加ボタンの無効化と登録時チェックの両方で12人制限。
5. **勝負服バリエーションを拡張済み**
   - 胴柄：無地、一本輪、二本輪、縦縞、たすき、市松、山形、水玉、ダイヤモンド、十字、ジグザグ、星、ひし形、ドット縦、波形
   - 袖柄：無地、一本輪、二本輪、縦切替、山形、水玉、袖口切替
   - 胴色・袖色・柄色も個別設定可能。
6. **レース追加時の入力エラー表示を修正**
   - エラー要素IDの不一致を修正。
7. **レース距離を保存**
   - 新規追加・編集の両方で距離を保持。

`index.html` / `app.js` / `style.css` / `config.js` / `supabase-setup.sql` はそのままGitHub Pagesへ置き換え可能です。
