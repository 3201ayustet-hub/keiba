# HORSE BET BATTLE v1.1

GitHub Pages + Supabaseで、ログインなしに複数端末から同じデータを閲覧・編集する静的Webアプリです。

## 配置ファイル

- `index.html`
- `style.css`
- `app.js`
- `config.js`（Project URL・Publishable Key設定済み）
- `supabase-setup.sql`
- `README.md`

ZIPを展開すると、すべて第1階層にあります。

## 導入

1. Supabase DashboardのSQL Editorで `supabase-setup.sql` 全文を実行します。
2. 6ファイルをGitHub Pagesの公開対象リポジトリ直下へアップロードします。
3. GitHub PagesのURLを開きます。
4. 別端末でも同じURLを開き、データが共有されることを確認します。

## 実装内容

- 勝負の作成・編集・削除
- ルール・賞品・連絡事項の自由記述
- 最大8人の参加者登録
- G1・G1以外レース登録
- レースごとの意気込み
- 賭け金・払戻額入力
- 通常時3,000円上限
- 5,000円権選択時5,000円上限
- G1以外権の残数管理
- 回収率・収支計算
- 最大払戻額チャンピオンカード
- 最大払戻額ランキング
- 回収率ランキング
- 個人成績画面
- 複数端末共有
- 5秒間隔の変更同期
- 同時更新の競合検知

## 注意

- 認証なしのため、URLを知る人は全データを閲覧・編集できます。
- `secret` または `service_role` キーは絶対にブラウザへ配置しないでください。
- GitHub Pagesの反映直後に古い画面が出る場合は、ブラウザを再読み込みしてください。
