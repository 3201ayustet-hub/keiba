# Horse Bet Battle v4.8

一撃王馬券を横長・高密度・明朝主体へ再設計した版です。

## 一撃王馬券 v4.8
- 横長レイアウト
- 情報密度を増加
- 明朝体を主要フォントに採用
- 左帯に開催日 / 競馬場 / G1・非G1 / レース名 / 記録ID
- 中央に大会名 / レース名 / 勝負服 / 参加者名 / 払戻額
- BET / RETURN / MEETING を下段に整理
- 払戻額を最大の主役として表示
- 鉛筆スケッチ風SVGを追加
  - 競馬場スタンド
  - 芝コース
  - ゴール板
  - 競走馬を抽象線画で表現
- バーコードと記録情報を下部に密集配置
- 右金帯は極細化

## デザイン方針
高級招待状ではなく「精密に組版されたプレミアム馬券」を狙っています。
装飾ではなく、情報密度・タイポグラフィ・罫線で高級感を作る設計です。

## 既存機能
- MAX PAYOUT BOARD 上位3名
- 順位推移 / 回収率 / 一撃王馬券
- 勝負服SVG
- 複数大会
- コンパクト管理UI
- iPhone Safariの日付入力重なり対策

Supabase構造変更なし。SQL再実行不要です。
