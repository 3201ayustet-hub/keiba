# 馬券勝負ボード MVP

ログインなしで、同じURLへアクセスした全員が共通データを操作できる競馬馬券勝負管理アプリです。

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` を開きます。

LAN内の別端末からアクセスする場合は、起動したPCのIPアドレスを使います。

```text
http://192.168.x.x:3000
```

インターネット公開する場合は、Node.jsが動くホスティングサービスへ配置してください。データは `data/db.json` に保存されます。

## 第1弾に含まれる機能

- 半年ごとの勝負作成
- トップの自由記述（ルール・賞品・連絡事項）
- 参加者登録（最大8人）
- レース登録（G1／G1以外）
- レースごとの意気込み
- 賭け金の自由入力
- 通常時3,000円上限
- 5,000円権選択時5,000円上限
- G1以外権の残数管理
- 払戻額入力
- 回収率・収支集計
- 最大払戻額ランキング
- レスポンシブ表示

## 注意

認証・権限管理はありません。URLを知っている人は全データを閲覧・編集できます。
