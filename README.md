# 馬券勝負ボード 第1弾（1端末版）

GitHub Pagesなどの静的サイトで動作する、ログイン・サーバー不要の試作版です。
データは利用中のブラウザの `localStorage` に保存されます。

## 使い方

1. `index.html`、`app.js`、`style.css` を同じ階層へ配置します。
2. GitHub Pagesへ公開するか、`index.html` をブラウザで開きます。
3. 「＋ 新しい勝負」から登録を開始します。

## 実装機能

- 勝負の作成・編集・削除
- トップ画面のルール・賞品・連絡事項
- 参加者登録（最大8人）
- G1／G1以外レース登録
- 参加者ごとの意気込み
- 賭け金・払戻額の入力
- 通常時3,000円上限
- 5,000円権選択時5,000円上限
- G1以外権
- 特殊権利残数（各3回）
- 回収率、収支、最大払戻額ランキング
- スマートフォン表示

## 注意

- データは端末・ブラウザごとに保存されます。
- ブラウザのサイトデータを削除すると、登録データも消えます。
- 別端末とのデータ共有には対応していません。
