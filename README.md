# Horse Bet Battle v4.6

v4.5をベースに、一撃王馬券を記念馬券風へ刷新し、
iPhone Safariのレース追加フォーム重なりを修正した版です。

## 一撃王馬券
京都競馬場リニューアル記念馬券の「記念券らしい雰囲気」を参考にしつつ、
実物券・JRAロゴ等は複製せず、Horse Bet Battle独自デザインで実装しています。

表示内容：
- 大会名
- レース日
- 競馬場
- G1 / 非G1
- レース名
- 勝負服
- 参加者名
- 賭け金
- 払戻額
- 回収率
- 競馬場・スタンドをイメージした線画
- バーコード風装飾
- 記録ID

## レース追加 / 編集
iPhone Safariの `input type="date"` が2列グリッド幅を超えて描画される問題に対して、
日付欄へ専用クラスを付与し、幅・appearance・overflowを個別制御しました。

- 開催日 / 競馬場
- 格 / 距離
の2列構成は維持
- 入力欄高さを36pxへ縮小
- 列間余白を固定
- 日付欄のはみ出しを抑制

## その他
- MAX PAYOUT BOARDは上位3名
- 順位推移 / 回収率 / 一撃王馬券 の3ボタン
- Supabase構造変更なし
- SQL再実行不要
