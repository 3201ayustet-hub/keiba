# Horse Bet Battle v4.7

テーマを「馬券」に固定し、一撃王馬券を再設計した版です。

## 一撃王馬券 v4.7
これまでの「記念証書寄り」から、現代的な高級デジタル馬券へ変更しました。

### デザイン方針
- 払戻額を最大の主役にする
- レース名を次に強調
- 勝負服＋参加者名をプレイヤー署名として表示
- BET / RETURN は補助情報へ
- 左サイド帯を細く
- 右金帯を極細化
- 建築線画をやめ、コース＋ゴール板の抽象線画へ
- バーコード / 記録ID / 大会名を下部へ整理
- 紙色70% / 深緑20% / 金10% の配色
- レース名は明朝、金額はMono、参加者名はSans

### スマホ
スマホで1画面に近い密度になるよう縦方向を圧縮しています。

## 既存機能
- MAX PAYOUT BOARD 上位3名
- 順位推移 / 回収率 / 一撃王馬券
- 勝負服SVG
- 複数大会
- コンパクト管理UI
- iPhone Safariの日付入力重なり対策

Supabase構造変更なし。SQL再実行不要です。
