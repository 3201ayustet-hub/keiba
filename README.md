# 馬券勝負ボード v2

1端末のブラウザだけで動作する静的Webアプリです。GitHub Pagesへそのまま配置できます。

## 起動

`index.html` をブラウザで開くか、4ファイルをGitHub Pagesの公開ルートへ配置してください。

## 保存先

データはブラウザのLocalStorageに保存されます。別端末・別ブラウザとは共有されません。

## v2の主な変更

- トップ画面をコンパクトな階層型ダッシュボードへ変更
- 最大払戻額1位を「現在の一撃王」として大きく表示
- 2位・3位を表彰台カードで表示
- 回収率ランキングをコンパクトな一覧化
- レース一覧をカード1行表示に変更し、詳細をモーダルへ分離
- 参加者をトップ最下部へ移動
- 参加者カードから個人成績ページを表示
- 個人成績に総回収率、収支、最大払戻、総払戻、権利残数、レース履歴を表示
