# HORSE BET BATTLE v2.1

仲間内の競馬・馬券勝負を管理する静的Webアプリです。Supabase の `app_state` 1行にJSONとしてデータを保存します。

## v2.1 改善
- 全入力フォームをスマホファースト化
- iPhone入力時の自動ズームを防ぐため入力文字を16px以上に統一
- モーダルをスマホでは下部シート化し、キーボード表示中もスクロール可能
- 保存ボタンをフォーム下部に追従表示
- 順位推移は最大20レースを想定し、初期表示を直近5レースへ
- 左スワイプで過去レースを確認
- 表示区間右端の順位に連動して参加者名を自動表示
- グラフのポイントをタップすると、その時点の順位・最大払戻額を表示
- 首位交代履歴をコンパクト化

## 更新方法
GitHub リポジトリの同名ファイルを上書きしてください。既存のSupabaseデータ構造は変更していないため、通常はSQLの再実行は不要です。
