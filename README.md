# Horse Bet Battle v4.5

v4.4をベースに、トップ画面の最大払戻ボードと分析導線、
一撃王馬券、レース追加フォームを改善した版です。

## v4.5変更点

### 最大払戻ボード
- トップ表示は上位3名だけ
- 4位以下は順位推移や参加者画面で確認

### 分析ボタン
- 順位推移
- 回収率
- 一撃王馬券
の3ボタンに変更

### 一撃王馬券
現在の最大払戻1位について、その記録を出したレースを
デジタル馬券風に表示します。

表示内容：
- レース名 / G1・非G1
- 日付
- 勝負服
- 参加者名
- 賭け金
- 払戻額
- 回収率
- 競馬場
- バーコード風装飾
- MAX PAYOUT表示

### レース追加 / 編集
- スマホ2列レイアウトを再調整
- 開催日 / 競馬場
- 格 / 距離
の枠が重ならないよう幅・余白・高さを固定
- 入力欄をさらに小型化

Supabase構造変更なし。SQL再実行不要です。
