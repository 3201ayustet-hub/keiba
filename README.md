# Horse Bet Battle v2.0

GitHub Pages + Supabaseで動作する、仲間内向けの馬券勝負管理アプリです。

## v2.0 主な変更
- 商用スポーツアプリを意識した黒・深緑・ゴールドのUI整理
- 一撃王（最大払戻額1位）を主役にし、2位・3位をコンパクト化
- 回収率の数値表記を改善（例: 20,000% / 83.3%）
- 登録レースを全件・日付順でコンパクト表示
- G1 / 非G1を視覚的に区別
- 参加者一覧をコンパクトなリスト形式へ変更
- 5,000円権 / G1以外権を「塗り＋枠＋残りx/3」で判別しやすく改善
- 最大払戻額ランキングの順位推移グラフを追加
- 首位が変わったレースを順位推移画面で確認可能
- 既存の追加・編集・削除・Supabase共有機能は維持

## 更新方法
このフォルダ直下の6ファイルをGitHubリポジトリの同名ファイルへ上書きしてください。

Supabaseのテーブル構成はv1.2から変更していないため、既に初期SQLを実行済みならSQLの再実行は不要です。
